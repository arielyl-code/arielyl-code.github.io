# 小麥醫師網站｜GitHub Pages 審閱版上線說明

## 準備好的檔案

請使用 `deliverables/github-pages-v1` 資料夾內的所有檔案；`index.html` 是對外首頁。

## 最簡單的上傳方式

1. 登入 GitHub，建立一個新的 repository。
2. 建議名稱：`dr-wheat-website-review`。
3. Visibility 可選 `Public`。GitHub 免費方案的 Pages 最容易使用公開 repository；這代表知道網址的人可瀏覽，也可能被搜尋引擎發現。
4. 進入 repository，選擇 **Add file → Upload files**。
5. 將 `github-pages-v1` 資料夾裡的所有內容拖入上傳區。請上傳「資料夾裡的內容」，不要只上傳 ZIP。
6. 完成 Commit。
7. 進入 **Settings → Pages**。
8. 在 **Build and deployment** 選擇 **Deploy from a branch**。
9. Branch 選 `main`，資料夾選 `/ (root)`，按下 Save。
10. 等待數分鐘，GitHub 會提供類似 `https://帳號.github.io/dr-wheat-website-review/` 的網址。

## 隱私提醒

- 目前是審閱雛形，表單不會傳送資料，社群連結多數仍是示意。
- 若 repository 設為 Public，網站內容等同公開。不要放入尚未同意公開的證書、病歷、個資、API key 或密碼。
- 若只希望少數人查看，GitHub Pages 並非真正的密碼保護。可改用 Cloudflare Access、付費私密預覽，或等待正式部署方案。

## 更新網站

未來修改後，只要重新上傳同名檔案並 Commit，GitHub Pages 會自動更新。圖片、CSS、JavaScript 與 HTML 的相對資料夾結構不要拆散。
