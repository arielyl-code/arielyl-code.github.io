# 小麥醫師網站｜黃醫師審閱版 v4

## 開啟方式

1. 將壓縮檔完整解壓縮。
2. 開啟資料夾中的 `index.html`。
3. 建議使用 Chrome、Safari 或 Edge 瀏覽。

## 審閱重點

- 首頁六大診療主題與滑動敘事。
- 診療項目、特色醫療、衛教文章與門診資訊的頁面架構。
- 甲狀腺射頻消融與酒精消融為兩個獨立頁面，可由特色醫療頁上方切換。
- 門診地圖為方向辨識示意圖，實際導航請使用頁面內的 Google 地圖按鈕。

## 注意事項

- 這是離線審閱原型，表單不會真的送出資料。
- 動畫、Notion 內容同步、正式網域、分析追蹤與正式部署尚未接上。
- 醫療文案在正式公開前，仍應由黃醫師完成最終專業審閱。
